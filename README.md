# UWUCALC
Интерактивный веб-калькулятор (Python, HTML, CSS, JavaScript)  Разработал веб-сервис для выполнения точных математических операций над обыкновенными и смешанными дробями. Реализовал алгоритм визуализации пошагового решения задач, адаптивную верстку интерактивных элементов UI и кастомизированный интерфейс ввода.
