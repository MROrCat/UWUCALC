# UWUCALC
Интерактивный веб-калькулятор (Python, HTML, CSS)  Разработал веб-сервис для выполнения точных математических операций над обыкновенными и смешанными дробями. Реализовал алгоритм визуализации пошагового решения задач, адаптивную верстку интерактивных элементов UI и кастомизированный интерфейс ввода. 
КАК ЗАПУСТИТЬ:
1. Закидываем файлы в одну папку кроме README.
2. открываем папку при помощи VSCode.
3. Открываем консоль и пишем py app.py
4. если вылетает ошибка связанная с 'flask', то прописывае в консоль py -m pip install flask
5. дожидаемся окончания загрузки и прописываем снова py app.py
6. далее копируем строчку с адресом, которую нам выдало, она начинается с http://
7. вставляем её в браузер и вуаля.
